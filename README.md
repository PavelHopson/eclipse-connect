Windows x64 приложение для диагностики доступности сервисов и ручного управления локальными компонентами FIX, Telegram-прокси и AmneziaWG. Это не VPN-сервис и не гарантия доступа к каждому сайту или приложению.

## Что делает

- Проверяет DNS, TCP/TLS и HTTPS отдельно; HTTP 200 не считается доказательством входа, отправки сообщений или воспроизведения видео.
- Управляет только собственными запусками компонентов. Внешние экземпляры FIX/VPN/прокси не останавливает.
- Предлагает ручную временную запись **только** `web.whatsapp.com` и `static.whatsapp.net` в Windows `hosts`, когда DNS выдаёт недоступный адрес. Перед изменением проверяет HTTPS и сертификаты, создаёт резервную копию, требует UAC и предлагает отдельный откат. Чужие записи `hosts` не переписывает. Адрес может устареть; работу приложения WhatsApp после применения нужно проверить вручную.
- Не переключает VPN, DNS и маршруты автоматически. FIX и выборочный VPN запускаются только явными действиями пользователя.

## Сборка

Нужны Windows x64, .NET SDK версии из `global.json` и PowerShell. В проекте нет приватных профилей VPN, ключей и настроек пользователя.

```powershell
.\scripts\prepare-awg-engine.ps1  # только подготовка проверенного движка, без установки
.\scripts\build.ps1
.\scripts\build.ps1 -Publish -OutputDirectory 'dist/releases/0.9.0'
```

`build.ps1` запускает автономные регрессии. Публикуемый EXE самодостаточен по .NET; для функции AmneziaWG ему нужны отдельные файлы из `components/amneziawg/3.1.0` рядом с EXE. Их подготовка и запуск — разные операции. Для FIX требуется собственный совместимый локальный движок; он не включён в исходники.

Офлайн-проверка интерфейса: запустить собранный EXE с `--self-test`. Этот режим не меняет сеть. Результат в `qa-data/render-results.json` рядом с тестовой сборкой. Не запускайте обычную версию параллельно с QA из того же каталога.

## Важно

- Ручная запись в `hosts` влияет на всю Windows, а не только на Eclipse Connect. После её применения проверьте WhatsApp; если доступ пропал или IP устарел, используйте кнопку отката в приложении. Резервные копии хранятся в `%LOCALAPPDATA%\EclipseConnect\backups`.
- Не публикуйте `.conf`, PrivateKey, `%LOCALAPPDATA%\EclipseConnect`, журналы и локальные резервные копии. EXE не подписан кодовым сертификатом.
- Для AmneziaWG используются сторонние компоненты с отдельными условиями распространения. Лицензия MIT в корне относится к собственным исходникам Eclipse Connect, не заменяет лицензии зависимостей.
- Автономные тесты не доказывают работу WhatsApp, Instagram, YouTube, Codex или VPN на конкретной сети. Проверка реального подключения остаётся ручной.

## Структура

`src/EclipseConnect.App` — WPF UI; `src/EclipseConnect.Core` — политика и операции; `tests/EclipseConnect.Tests` — автономные регрессии; `scripts` — сборка и подготовка компонентов.
